# Manuals

The user and admin manuals are the in-app Help pages. Their source is the Markdown in `frontend/src/help/`, one folder per profile, so the app and this repository always show the same text.

In the app: **Help** in the left menu. Each profile sees its own guide plus the common topics; super-admins also see the other guides.
