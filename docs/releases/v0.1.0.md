# Mentis v0.1.0

First release. SOC analysts ask questions about each customer's procedures and get answers only from that customer's documentation, with the source of every statement.

## What is in it

- **Chat**: `@` customer (locked by the first message) or All customers. Numbered sources (customer, document, version, page, passage). "Not found" instead of guessing. Suggested follow-ups, history, feedback. Chats are private.
- **Documents**: PDF, Word, Excel and PowerPoint, with OCR. Versions, approval, and a preview of what Mentis read. A General knowledge base shared by every customer.
- **AI**: Claude, OpenAI, Daybreak Blue, gpt-oss (vLLM) and Ollama. One LLM per customer with a fallback. Local embeddings (bge-m3) and Qdrant.
- **Administration**: tenants, users and invitations, SMTP, mandatory 2FA, three themes, in-app help for each profile.
- **Operations**: service status, **Logs** with CSV export and **syslog forwarding** to a SIEM, **retention**, **LLM usage and cost** per customer, **backup/restore** scripts, **configuration export/import**.

## Known limits

- `#` integrations (ticketing, EDR, SIEM) are not available yet.
- Tables in PDFs without ruling lines are read as text rows. The Docling parser is optional and not verified.
- `MENTIS_CHAT_MIN_SCORE=0.3` is a first guess for bge-m3. Tune it with real documents.
- The `qdrant` and `minio` images use the `latest` tag.

## New installation

On the server, as a user who can run Docker:

```bash
sudo mkdir -p /opt/mentis && sudo chown "$USER" /opt/mentis
git clone https://github.com/thevidocq/mentis.git /opt/mentis
cd /opt/mentis
git checkout v0.1.0
cp .env.example .env
# Fill every secret with a random value
sed -i "s/^MENTIS_SECRET_KEY=.*/MENTIS_SECRET_KEY=$(openssl rand -hex 32)/" .env
for k in POSTGRES_PASSWORD MINIO_ROOT_PASSWORD QDRANT_API_KEY REDIS_PASSWORD; do
  sed -i "s/^$k=.*/$k=$(openssl rand -hex 24)/" .env
done
# Address users open (behind your HTTPS nginx); keep MENTIS_COOKIE_SECURE=true with HTTPS
sed -i "s|^MENTIS_PUBLIC_URL=.*|MENTIS_PUBLIC_URL=https://mentis.example.com|" .env
grep -n CHANGE_ME .env || echo "secrets set"
chmod 600 .env
docker compose up -d --build
docker compose logs -f embeddings    # first start downloads bge-m3 (~2.3 GB); Ctrl+C at "Ready"
./check.sh
```

Then open `http://127.0.0.1:8080` (or your HTTPS nginx, see INSTALL.md) and:

1. Create the super-admin and enroll 2FA.
2. **AI providers → Add provider → Claude Haiku**: paste the API key, **Save**, **Test**.
3. **Email (SMTP)**, **Tenants**, **Users**, **General documentation**.
4. **Retention** and, if you have a SIEM, **Logs → Syslog forwarding**.
5. Schedule the nightly backup (see below).

## Upgrade from an earlier version

```bash
cd /opt/mentis
./backup.sh 2>/dev/null || echo "backup.sh arrives with this release: take a manual backup first if you have data"
git fetch --tags
git checkout v0.1.0
grep -q MENTIS_CHAT_MIN_SCORE .env || cat >> .env <<'ENV'

# Chat retrieval
MENTIS_CHAT_PASSAGES=8
MENTIS_CHAT_MIN_SCORE=0.3
ENV
docker compose up -d --build
./check.sh
docker compose logs --tail=50 api | grep -i -E "error|alembic"
```

Database migrations run automatically when the `api` container starts. 0.1.0 adds migration 0004 (AI providers and chats).

## Post-install / post-upgrade check

```bash
cd /opt/mentis
./check.sh                                    # every container running, API reachable through the web proxy
docker compose ps
docker compose exec api python -c "import app; print(app.__version__)"      # 0.1.0
# The API must reach the LLM provider over HTTPS: 401 is fine (no key sent), a timeout is not
docker compose exec api python -c "import httpx; print(httpx.get('https://api.anthropic.com/v1/models').status_code)"
./backup.sh && ls -la backups/                # a first backup works
```

In the app, as super-admin:

- **Service status**: every line Operational, including `LLM: …`.
- **Chat**: `@customer` and a question that a document answers. Check the customer label and click the source number. Then ask something the documents do not cover: **Not found**.
- **Logs**: the `chat.answered` event shows model, tokens and time, not the question.
- **LLM usage**: the question appears under the customer.

## Nightly backup

```bash
crontab -e
30 2 * * * cd /opt/mentis && ./backup.sh >/var/log/mentis-backup.log 2>&1 && find backups -maxdepth 1 -name 'mentis-*' -mtime +14 -exec rm -rf {} +
```

Backups contain `.env` with every secret. Copy them off the server and keep them encrypted. To restore: `./restore.sh backups/mentis-<date>` (add `--with-env` on a new server).
