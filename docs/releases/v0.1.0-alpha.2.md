# Mentis v0.1.0-alpha.2

Second pre-release, for the lab. First version where analysts can **ask questions and get answers** from customer documentation. **Not for production** yet: Logs, retention and backup are still missing.

## What is new

- **Chat**: `@` customer (All customers by default, locked by the first message), answers only from the documents in use with numbered sources (customer, document, version, page, passage), "Not found" instead of guessing, up to 3 suggested follow-ups, automatic titles, history with search, rename and delete, thumbs up/down. Chats are private.
- **AI providers** (super-admin): Claude (Anthropic), OpenAI, Daybreak Blue and gpt-oss (Responses API), Ollama/vLLM; API keys encrypted; Test button; platform default.
- **Per-tenant LLM** with a fallback used automatically when the first model fails (tenant admin **LLM** page, or the brain icon in **Tenants**).
- Tenant admins can chat on their own customer to test answers.
- Service status: one line per AI provider (checks address and key without spending tokens).
- Help: Using the chat, LLM and testing answers, AI providers.

## Known limits

- `#` integrations are not available yet (button shown as "soon").
- Logs page, retention, backup/restore and configuration import/export are not there yet.
- LLM usage per tenant (tokens, cost) is recorded but not shown yet.
- Retrieval threshold `MENTIS_CHAT_MIN_SCORE=0.3` is a first guess for bge-m3: tune it with real documents.
- Daybreak Blue needs approval in OpenAI's program before its preset works.

## Upgrade from v0.1.0-alpha.1

```bash
cd mentis
git fetch --tags
git checkout v0.1.0-alpha.2
grep -q MENTIS_CHAT_MIN_SCORE .env || cat >> .env <<'ENV'

# Chat retrieval
MENTIS_CHAT_PASSAGES=8
MENTIS_CHAT_MIN_SCORE=0.3
ENV
docker compose up -d --build
./check.sh
docker compose logs --tail=30 api | grep -i -E "error|alembic"
```

The database migration (0004: AI providers and chats) runs automatically when the `api` container starts.

## New install

```bash
git clone https://github.com/thevidocq/mentis.git && cd mentis
git checkout v0.1.0-alpha.2
cp .env.example .env
sed -i "s/^MENTIS_SECRET_KEY=.*/MENTIS_SECRET_KEY=$(openssl rand -hex 32)/" .env
nano .env        # set every CHANGE_ME and MENTIS_PUBLIC_URL
docker compose up -d --build
docker compose logs -f embeddings   # first start downloads the model (~2.3 GB); Ctrl+C when "Ready"
./check.sh
```

## Post-upgrade check

1. `./check.sh`: every container running, API reachable through the web proxy.
2. The API can reach the LLM provider:
   ```bash
   docker compose exec api python -c "import httpx; print(httpx.get('https://api.anthropic.com/v1/models').status_code)"
   ```
   `401` is fine here (no key sent); a timeout or DNS error means no outbound HTTPS.
3. In the app, as super-admin:
   - **AI providers → Add provider → Claude Haiku**, paste the API key, **Save**, **Test** → "answered: ready".
   - **Service status**: the `LLM: …` line is Operational.
   - Upload a real procedure to a customer, wait for **Ready**, then **Chat**: `@customer`, ask a question it answers. Check the customer label, click the source number and read the passage.
   - Ask something the documents do not cover → **Not found**.
