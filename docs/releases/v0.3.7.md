# Mentis v0.3.7

Stability release: no new features, no migration.

## Fixed

- **Storage sweep**: a document uploaded while the daily sweep was running could lose its files (taken for a leftover). The sweep now lists the storage first and reads the database afterwards.
- **Answer check, "Hide the answer" mode**: if the model failed while rewriting a wrong answer, the wrong answer was shown unchecked. It now stays hidden.
- **Answer check**: an unexpected error in the check (level 1 or 2) now gives "Check not available" and never breaks or loses the answer.
- **Answer check, level 1**: year ranges (2023-2024), ISO dates (2024-05-12), number ranges and amounts (1.000.000) are no longer read as phone numbers.
- A hidden answer no longer goes back to the LLM with a misleading note.
- Chat: "Checking…" no longer stays forever when a check is slow; after 2 minutes it shows "Check not available".

## Before the upgrade

```bash
cd ~/mentis
git status --short          # must print nothing
docker compose ps
./backup.sh
```

## Upgrade

```bash
cd ~/mentis
git fetch --tags
git checkout v0.3.7
docker compose up -d --build --remove-orphans
docker compose ps
docker image prune -f && docker builder prune -f
```

## Post-upgrade check

```bash
sudo ./check.sh
docker compose exec api python -c "import app; print(app.__version__)"     # 0.3.7
docker compose exec postgres psql -U mentis -d mentis -c "select version_num from alembic_version"     # 0012
docker compose logs api | grep -i -E "alembic|error|refusing" | tail -5
```

In the browser (Ctrl+F5): ask a question in a chat, under the answer "Checking…" then "Matches the sources".
