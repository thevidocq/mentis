# Mentis v0.3.5

## What is new

- **Documents as a document browser**: the list on the left (search, All / In use / To review, problems grouped on top), the selected document on the right with its actions (Approve, Retry, New version, Download, ⋯ for Rename and Delete) and the tabs Preview, Text read, Versions, Test a question.
- **New version** of a document accepts a file with any name (same type).
- **Chat**: answers in a light frame, the customer as small text instead of a rounded badge; Sources in a compact card on the right.
- **Backup fixed**: `backup.sh` no longer stops with "No such image" after rebuilds.
- **Small servers**: `MENTIS_EMBEDDING_BATCH_SIZE` in `.env` now works (4 = less memory for the embedding service). Plan at least 8 GB RAM, or add swap.

No database migration.

## Before the upgrade

```bash
cd ~/mentis
git status --short          # must print nothing
docker compose ps
free -h                     # with less than 8 GB total and no swap, see "Little RAM" below
```

## Upgrade

```bash
cd ~/mentis
git fetch --tags
git checkout v0.3.5
./backup.sh                 # the fixed script: must end without errors
docker compose up -d --build --remove-orphans
docker compose ps
```

## Post-upgrade check

```bash
./check.sh
docker compose exec api python -c "import app; print(app.__version__)"     # 0.3.5
docker compose exec worker python -c "from app.core.config import get_settings as g; print(g().embedding_batch_size)"
docker compose logs api | grep -i -E "error|refusing" | tail -5
```

In the browser (Ctrl+F5): open **Documents**, select a document, try the tabs and **⋯**; open a chat answer and its **Sources**.

## Little RAM (less than 8 GB, no swap)

```bash
sudo fallocate -l 4G /swapfile && sudo chmod 600 /swapfile && sudo mkswap /swapfile && sudo swapon /swapfile
grep -q '^/swapfile' /etc/fstab || echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
cd ~/mentis
grep -q '^MENTIS_EMBEDDING_BATCH_SIZE=' .env || echo 'MENTIS_EMBEDDING_BATCH_SIZE=4' >> .env
docker compose up -d
```

Then **Retry** the failed documents (Documents → the document under *Needs attention* → **Retry**).
