# Mentis v0.1.0-alpha.1

First pre-release, for installation in the lab. **Not for production**: the chat is not available yet.

## What is in it

- First-run setup, sign-in with mandatory TOTP 2FA, roles (super-admin, tenant admin, analyst), invitations by email or link, SMTP.
- Tenants with the General knowledge base; account page with Light/Medium/Dark themes; in-app Help per profile.
- Documents: validated upload (PDF, DOCX, PPTX, XLSX), versions, OCR, side-by-side preview, approval before publishing.
- Indexing with local embeddings (bge-m3) and Qdrant; "test a question" in the preview; Embedding and Qdrant page with reindex.
- Service status for every component.

## Known limits

- No chat and no LLM providers yet (next: v0.1.0).
- Tables in PDFs without ruling lines are read as text rows.
- Docling parser available but not verified (`MENTIS_PARSER=docling`).
- The Logs page, retention, backup and configuration import/export are not there yet.

## Install

```bash
git clone https://github.com/thevidocq/mentis.git && cd mentis
git checkout v0.1.0-alpha.1
cp .env.example .env
sed -i "s/^MENTIS_SECRET_KEY=.*/MENTIS_SECRET_KEY=$(openssl rand -hex 32)/" .env
nano .env        # set every CHANGE_ME and MENTIS_PUBLIC_URL
docker compose up -d --build
docker compose logs -f embeddings   # first start downloads the model (~2.3 GB); Ctrl+C when "Ready"
./check.sh
```

Open http://127.0.0.1:8080 (or your nginx with HTTPS in front of it) and complete the first-run setup.

## Upgrade from an earlier checkout

```bash
cd mentis
git fetch --tags
git checkout v0.1.0-alpha.1
grep -q MENTIS_EMBEDDING_URL .env || cat >> .env <<'ENV'
MENTIS_WORKER_REPLICAS=1
MENTIS_EMBEDDING_URL=http://embeddings/v1
MENTIS_EMBEDDING_MODEL=BAAI/bge-m3
MENTIS_EMBEDDINGS_CPUS=2
MENTIS_EMBEDDINGS_MEMORY=4g
ENV
docker compose up -d --build
./check.sh
```

## Post-install check

- `./check.sh` shows every container running and the API reachable through the web proxy.
- In the app: **Service status** all Operational; **Embedding and Qdrant → Test connection** reports bge-m3 with 1024 dimensions.
- Upload a real procedure to **General documentation**, open its preview and use **Test a question**.
