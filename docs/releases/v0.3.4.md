# Mentis v0.3.4

Includes v0.3.3 (pages centered next to the menu).

## What is new

- **Share a chat by link**: **Share** in the chat header. The link opens the chat read-only, with its sources, only for colleagues signed in to Mentis who see the chat's customer (for an "All customers" chat: all the customers it searched). Answers about customers the colleague does not see stay hidden. One link per chat, valid 30 days, revocable; every creation, revocation and opening is in Logs.
- **Sources panel on the right**: the Sources bar and the [n] numbers open the cited documentation beside the chat, no longer under the answer.
- Wider side menu; the header lines of menu and page are aligned.
- Admin sidebar: **Tenant** instead of Customer, with more space around the tenant switcher.
- `check.sh`: no more false "CHANGE_ME placeholders" error from the comment at the top of `.env`.

Migration 0011 (new table `chat_shares`), applied automatically at start.

## Before the upgrade

```bash
cd ~/mentis
git status --short          # must print nothing
docker compose ps           # all services up
./backup.sh
```

## Upgrade

```bash
cd ~/mentis
git fetch --tags
git checkout v0.3.4
docker compose up -d --build --remove-orphans
docker compose ps
```

## Post-upgrade check

```bash
./check.sh        # every line OK (the CHANGE_ME line too)
docker compose exec api python -c "import app; print(app.__version__)"     # 0.3.4
docker compose exec postgres psql -U mentis -d mentis -c "select version_num from alembic_version"     # 0011
docker compose logs api | grep -i -E "alembic|error|refusing" | tail -5
```

Then in the browser (Ctrl+F5 to reload the new frontend):

1. Open a chat, click **Sources**: the panel opens on the right.
2. Click **Share** → **Create link**: the link is copied.
3. Open the link signed in as another analyst or tenant admin of the same customer: the chat shows read-only. In **Logs**, filter the action `chat.share*`.

## If something fails

- `docker compose logs --tail=50 api`: an error on migration 0011 → send the output to the developer; restore with `./restore.sh` from the backup made before.
- The link says "invalid, revoked or expired": the colleague does not see the chat's customer, or the link was replaced by a newer one.
