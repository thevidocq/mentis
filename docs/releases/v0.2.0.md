# Mentis v0.2.0

## What is new

- **Tenant admins of several customers.** When inviting or editing a tenant admin you tick its customers. In the tenant area a selector at the top of the menu picks the customer. In the chat, `@` shows only its customers plus **All my customers**. Existing tenant admins are migrated automatically.
- **Usable from a phone.** The menu and the chat history open from the ☰ button, tables become cards, the chat fills the screen and dialogs open from the bottom.
- **Super-admin from the server:** `docker compose exec api python -m app.cli create-admin`. The browser setup page is off by default.
- **Web port in `.env`:** `MENTIS_WEB_PORT` (8080 by default), also read by `check.sh`.
- Internal services (API, PostgreSQL, Qdrant, MinIO, Redis) no longer publish any host port.
- Fixes: TOTP codes usable once, documents stuck in Processing recovered, back to sign-in when the session expires, security headers now on every page, client IP in Logs can no longer be spoofed, API docs no longer public, syslog no longer loses events from document processing, a hint instead of "Not found" for "ciao".
- Includes v0.1.1 (MinIO image from the community fork `pgsty/minio`).

## Upgrade

Take a backup, put back the files edited by hand (their settings go into `.env`), then switch version:

```bash
cd ~/mentis
./backup.sh
git checkout -- docker-compose.yml check.sh
grep -q '^MENTIS_WEB_PORT=' .env || echo "MENTIS_WEB_PORT=8090" >> .env     # the port you use
grep -q '^MENTIS_WEB_SETUP=' .env || echo "MENTIS_WEB_SETUP=false" >> .env
git fetch --tags
git checkout v0.2.0
docker compose up -d --build
docker compose ps
./check.sh
```

`docker-compose.override.yml` (the link to the Caddy of Equalizer) is not touched.

The database migrations 0005 (tenant admins on several customers), 0006 (one-time TOTP codes) and 0007 (recovery of stuck documents) run when the `api` container starts. Check it:

```bash
docker compose logs api | grep -i -E "alembic|error" | tail -5
docker compose exec api python -c "import app; print(app.__version__)"     # 0.2.0
```

## Post-upgrade check

1. `./check.sh`: every line OK, frontend on your `MENTIS_WEB_PORT`.
2. Security headers on the page:
   ```bash
   curl -sI https://mentis.thevidocq.com | grep -i -E "content-security-policy|x-frame-options"
   ```
3. The API docs are no longer public (expected: 404):
   ```bash
   curl -s -o /dev/null -w "%{http_code}\n" https://mentis.thevidocq.com/api/docs
   ```
4. From the phone: open the site, ☰ menu, **Users → Invite user**: the customers can be ticked.
5. A tenant admin of two customers sees the selector in the menu and **All my customers** after `@` in the chat.
