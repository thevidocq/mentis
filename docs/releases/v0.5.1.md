# Mentis v0.5.1

Clearer answer check and no more answers cut silently. No migration.

## Fixed

- **Answers cut mid-sentence**: an answer longer than the AI provider's token limit was saved cut, without notice. The default limit is now 4,000 tokens (was 1,500), still adjustable per model (**AI providers → Advanced → Max answer tokens**), and an answer cut at the limit ends with a note saying so.
- **Fewer false warnings**: items of a list take the citation of their heading ("If it is a true positive [2]") and are checked against that passage; a heading with steps under it is no longer a statement to cite. Answers no longer open with sentences about where the passages come from: the source is shown above each answer, and those sentences were flagged as uncited or unsupported.
- An answer from the General Knowledge Base is a normal answer, not a warning.

## Changed

- **Answer check in the text**: a statement that may not match its sources is underlined in yellow with a small ⚠ after its source number; pointing at it (or tapping it) shows the level, what was found and **Open passage ›**.
- **Under the answer**: one line, *Matches the sources* or *N statements may not match the sources: check the marked ones*. The list of repeated lines and the per-line *Open source* links are gone.

## What changes for you

- Analysts see far fewer warnings; each one is next to the statement it concerns.
- Long answers can use more tokens (only when the answer is long).

## Before the upgrade

```bash
cd ~/mentis
git status --short
./backup.sh
```

## Upgrade

```bash
cd ~/mentis
git fetch --tags
git checkout v0.5.1
docker compose up -d --build --remove-orphans
docker compose ps
docker image prune -f && docker builder prune -f
```

## Post-upgrade check

```bash
sudo ./check.sh
docker compose exec api python -c "import app; print(app.__version__)"
docker compose logs api worker | grep -i -E "error|traceback" | tail -10
```

Expected: `0.5.1`; no new errors. In the browser: ask a procedure question with several steps (e.g. an alert from the General Knowledge Base): the answer is complete and shows *Matches the sources*; on an answer with a warning, point at the ⚠ after a source number and check the box opens.

## Rollback

v0.5.1 has no migration: going back to v0.5.0 needs no restore.

```bash
cd ~/mentis
git checkout v0.5.0
docker compose up -d --build --remove-orphans
```
