# Mentis v0.3.6

## What is new

- **Answer check, against hallucinations**, in two levels:
  - **Level 1** (always on, no model, no cost): contacts, times, durations, codes and other critical values in the answer must be in the sources; answers without citations are flagged.
  - **Level 2**: a model re-reads each statement against its sources.
- In the chat the wrong value or statement is highlighted, and a quiet line under the answer says which level found it (**Level 1**, **Level 2**, **Level 1 + 2**), with **Open source ›**.
- Per customer, **LLM** page: *Show a warning* (default), *Hide the answer*, or *Don't check with a model*.
- **AI providers**: two sections, **Answers** and **Answer check**; **Use for** when adding a model; **Set as default** to change the default (adding a model never changes it); **Test** of a checker checks it catches a planted error.
- Answers with temperature 0 (repeatable).
- Logs `chat.checked`; costs of the checks in **LLM usage**.

Migration 0012, applied automatically at start.

## Before the upgrade

```bash
cd ~/mentis
git status --short          # must print nothing
docker compose ps
./backup.sh
```

## Upgrade

```bash
cd ~/mentis
git fetch --tags
git checkout v0.3.6
docker compose up -d --build --remove-orphans
docker compose ps
docker image prune -f && docker builder prune -f
```

## Post-upgrade check

```bash
sudo ./check.sh
docker compose exec api python -c "import app; print(app.__version__)"     # 0.3.6
docker compose exec postgres psql -U mentis -d mentis -c "select version_num from alembic_version"     # 0012
docker compose logs api | grep -i -E "alembic|error|refusing" | tail -5
```

In the browser (Ctrl+F5):

1. Ask a question in a chat: under the answer, "Checking…" then "Matches the sources".
2. Optional: **AI providers → Add provider → Use for: Answer check** (a small model, e.g. Claude Haiku), **Save**, **Test**: it must catch the planted error.
3. **LLM** page of a customer: **Answer check** shows the three options (default *Show a warning*).
4. **Logs**, action `chat.checked`; **LLM usage**, rows "· answer check".
