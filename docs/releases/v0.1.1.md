# Mentis v0.1.1

Fix for installation: `docker compose up` failed with `pull access denied for minio/minio`.

MinIO, Inc. deleted its free images from Docker Hub (and requires an account on Quay). The `minio` service now uses **`pgsty/minio`**, the community-maintained fork of MinIO, pinned to `RELEASE.2026-03-25T00-00-00Z`. It is a drop-in replacement: same data format, same `MINIO_*` settings, existing data is kept.

Everything else is as in [v0.1.0](v0.1.0.md).

## Install or upgrade

```bash
cd ~/mentis            # your installation folder
git fetch --tags
git checkout -- docker-compose.yml   # drop any local edit to the compose file
git checkout v0.1.1
docker compose up -d --build
./check.sh
docker compose exec api python -c "import app; print(app.__version__)"   # 0.1.1
```

New installation: follow [v0.1.0](v0.1.0.md) with `git checkout v0.1.1`.
