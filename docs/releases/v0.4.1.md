# Mentis v0.4.1

Security fixes from the v0.4.0 vulnerability assessment ([docs/security/va-pt-v0.4.0.md](../security/va-pt-v0.4.0.md)). No migration.

## Fixed

- **Answer check**: a statement without a citation is flagged (*"cites no source"*) instead of passing unchecked; values must be in the passages the statement cites.
- **Integration credentials** are bound to the address **and** to the account fields (tenant ID, client ID, child CID, account, projects, region): changing one requires the credentials again.
- **Integration destinations**: HTTPS only, public addresses only by default; Mentis' own services, loopback and cloud metadata always refused. Super-admins can allow private network addresses for on-premise systems (Integrations page).
- **Limits**: 30 s per integration call in total, 6 calls at once, 2 MB per answer after decompression; per-user limits on chat (30/min), Test and Try a lookup (20/min), exports (10/min); one "download all" ZIP at a time, capped in every format.
- **Prompt injection**: passage tags (opening and closing, lookalike characters) neutralised in the answer and checker prompts.
- Function calling chosen by a tenant admin lapses when the customer goes back to the platform LLM.
- Secret key rotation (`MENTIS_SECRET_KEY_PREVIOUS`), plugin packages restricted to `mentis-*`, pinned plugin build.

## What changes for you

- An integration whose address is plain `http://` or a private address stops working until a super-admin enables **Private network addresses** (Integrations page).
- Analysts may see *"1 statement cites no source"* under answers that used to show *Matches the sources*.

## Before the upgrade

```bash
cd ~/mentis
git status --short
./backup.sh
```

## Upgrade

```bash
cd ~/mentis
git fetch --tags
git checkout v0.4.1
docker compose up -d --build --remove-orphans
docker compose ps
docker image prune -f && docker builder prune -f
sudo iptables -C DOCKER-USER -d 169.254.169.254 -j DROP 2>/dev/null || sudo iptables -I DOCKER-USER -d 169.254.169.254 -j DROP
```

## Post-upgrade check

```bash
sudo ./check.sh
docker compose exec api python -c "import app; print(app.__version__)"
docker compose exec api python -c "from app.connectors import registry; print(sorted(registry.connectors()))"
docker compose logs api | grep -i -E "error|plugin|decrypt" | tail -10
```

Expected: `0.4.1`; the six plugins; no "could not be decrypted" line. In the browser: Integrations → **Test** on each integration; a chat with `#` answers with links.

## Rollback

v0.4.1 has no migration: going back to v0.4.0 needs no restore.

```bash
cd ~/mentis
git checkout v0.4.0
docker compose up -d --build --remove-orphans
```

Going back further than v0.4.0 (database at revision 0013) needs the backup taken before v0.4.0: `./restore.sh <that backup>`.
