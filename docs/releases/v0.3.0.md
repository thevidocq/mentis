# Mentis v0.3.0

## What is new

- **Granular access.** Tenant admins and analysts see only the customers ticked on their account. **General** (shared documentation) is ticked by default and can be removed. **All customers, including future ones** gives every customer, also those created later.
- **Tenant admins invite tenant admins and analysts**, only with customers they have themselves. They see only the users they can manage and cannot change their own role or customers. Everything is in Logs.
- **The super-admin manages the platform only**: no chat, no documents. **General documents are managed by tenant admins who have General.**
- Per customer, the super-admin decides whether its tenant admins can choose the LLM (Tenants → brain icon → *Tenant admins can choose the LLM of this customer*).
- Tenant admins see AI providers as name + model only, and LLM usage without costs.
- **General in the chat**: `@` ends with General, to ask the shared documentation alone.
- **Log out like Equalizer**: at the bottom of the menu, next to your name, Help (?) and a red Log out button.
- **Document pipeline review**: reindex with no documents, model changed without reindex, Qdrant or Redis down, huge Excel cells, documents deleted while processing. The embedding container now truncates over-long texts instead of failing (it restarts once during the upgrade).
- Fixes (they were listed in 0.2.0 but missed that release): TOTP codes usable once, documents stuck in Processing recovered, wrong current password counted as a failed sign-in, expired sessions and invitations purged, back to sign-in when the session expires, blank names refused.

## Before upgrading

- Existing **analysts** become *All customers* (same as today). Untick customers later if needed.
- Existing **tenant admins** keep their customers and also get **General**: remove it from those who must not manage the shared documentation.
- Chats of super-admins stay in the database but are no longer reachable.
- After the upgrade, give **General** to at least one tenant admin, otherwise nobody can update the General documents.

## Upgrade

```bash
cd ~/mentis
./backup.sh
git fetch --tags
git checkout v0.3.0
docker compose up -d --build
docker compose ps
./check.sh
```

`.env` and `docker-compose.override.yml` are not touched.

The migrations 0006 (one-time TOTP codes), 0007 (recovery of stuck documents) and 0008 (granular access) run when the `api` container starts. Check it:

```bash
docker compose logs api | grep -i -E "alembic|error" | tail -5
docker compose exec api python -c "import app; print(app.__version__)"     # 0.3.0
docker compose exec postgres psql -U mentis -d mentis -c "select version_num from alembic_version"     # 0008
```

## Post-upgrade check

1. `./check.sh`: every line OK.
2. As super-admin: the menu has no **Chat** and no **General documentation**; **Users → Invite user** shows the customers with **General** ticked and **All customers, including future ones**.
3. **Users**: analysts show *All customers (also future)*; give **General** to a tenant admin if none has it.
4. **Tenants → brain icon**: the option *Tenant admins can choose the LLM of this customer* is there.
5. Bottom of the menu: your name, **?** and the red **Log out**, with `Mentis 0.3.0` underneath.
6. As a tenant admin: **Invite user** offers *Analyst* and *Tenant admin*, with only your customers; **LLM** shows no prices or costs.
7. As an analyst with one customer: `@` in the chat lists only that customer.
