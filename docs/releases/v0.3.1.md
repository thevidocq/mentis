# Mentis v0.3.1

## What is new

- **Models from the provider.** In **AI providers**, **Load models** lists the models the provider offers (Anthropic, OpenAI, Ollama, vLLM), newest first; pick one, or **Other** to type a name. Presets no longer contain model names.
- **Forgot password?** on the sign-in page sends a one-time link by email (60 minutes). Admins can create a reset link from **Users** (envelope icon), emailed or shown to copy when email is not configured. The authenticator app is still required to sign in.
- **Compact sources**: one closed line under the answer ("Sources · 1 document · 8 sections"), grouped by document, sections in order.
- **Chat menu**: logo on its own row, search box with a **+** for a new chat.
- **Account** opens inside the usual menu; no more "Sign out" at the top; compact themes on the phone.
- **Customer selector with search** in the tenant area (General first, then the last used), and search in the customer list of invitations.
- **Faster upgrades from the next release on**: Tesseract, Python packages and `npm ci` stay cached. This upgrade still installs everything once.
- **Bugfixes** (see CHANGELOG): parallel password/2FA guesses could slip past the lockout, PDFs with only print restrictions were refused, empty-but-formatted Excel cells flooded answers, a late old version could replace the active one, API keys echoed by providers were not hidden, local models' JSON with line breaks was shown raw, the web proxy could keep an old API address after a restart, `restore.sh` and `backup.sh` fixes, `check.sh` now spots a failed upgrade build.

## Upgrade

```bash
cd ~/mentis
./backup.sh
git fetch --tags
git checkout v0.3.1
docker compose up -d --build
docker compose ps
./check.sh
```

The build is long one more time (like 0.3.0): it reorganises the cache. From the next release on, upgrades rebuild only the code.

Migration 0009 (password reset links) runs when the `api` container starts. Check it:

```bash
docker compose logs api | grep -i -E "alembic|error" | tail -5
docker compose exec api python -c "import app; print(app.__version__)"     # 0.3.1
docker compose exec postgres psql -U mentis -d mentis -c "select version_num from alembic_version"     # 0009
```

## Post-upgrade check

1. `./check.sh`: every line OK. It now also says FAIL if the API runs another version than the checkout (a failed build).
2. **AI providers → edit your provider**: the model is a list loaded from the provider; **Reload** refreshes it.
3. Sign out, then **Forgot password?** on the sign-in page: with SMTP configured, the email arrives; without it, use the envelope icon in **Users** instead.
4. A chat answer: **Sources** is one line; open it to see the document and its sections.
5. Phone: chat menu with search and **+**; **Account** opens inside the menu.
6. Tenant admin with several customers: the customer selector opens with **Search customers…**.
