# Mentis v0.5.2

Better answers to questions that ask several things, and two new customer settings. No migration.

## Added

- **Passages read per answer** (customer **Settings**, tenant admin and super-admin): how many passages of documentation the AI reads to answer, 3 to 20. Empty = the platform value `MENTIS_CHAT_PASSAGES` (8).
- **Questions that ask several things** (customer **Settings**): passages are chosen to be relevant **and** different from each other (Maximal Marginal Relevance), so a question asking two things (a procedure and a contact, say) finds passages for both. **Normal** by default, **High** for more variety, **Off** for the previous behaviour.

## Fixed

- **Answer check**: a short line introducing a list ("Checks to run on the server [1][2]:") no longer gets a false warning.

## What changes for you

- Questions about one thing get the same answers as before.
- Questions combining two requests now usually answer both.
- With a reasoning model such as gpt-oss, set **Max answer tokens** to about 8000 (AI providers → Advanced): its reasoning counts in the limit.

## Before the upgrade

```bash
cd ~/mentis
git status --short
./backup.sh
```

## Upgrade

```bash
cd ~/mentis
git fetch --tags
git checkout v0.5.2
docker compose up -d --build --remove-orphans
docker compose ps
docker image prune -f && docker builder prune -f
```

## Post-upgrade check

```bash
sudo ./check.sh
docker compose exec api python -c "import app; print(app.__version__)"
docker compose logs api worker | grep -i -E "error|traceback" | tail -10
```

Expected: `0.5.2`; no new errors. In the browser: a customer's **Settings** shows **Passages read per answer** and **Questions that ask several things**; a question asking two things (e.g. an alert procedure and a contact from another document) answers both.

## Rollback

v0.5.2 has no migration: going back to v0.5.1 needs no restore (the two new settings are ignored by v0.5.1).

```bash
cd ~/mentis
git checkout v0.5.1
docker compose up -d --build --remove-orphans
```
