# Mentis v0.6.3

Security and accuracy release after a review of 0.6.2 (`docs/security/review-v0.6.2.md`). **Migration 0016.**

## Security and accuracy

- **The answer check covers everything shown.** Code blocks, table rows, headings and short or uncited sentences could get "Matches the sources" without being checked. Every line is now checked, read exactly as the chat shows it; level 1 compares many more SOC values (IOCs, hashes, paths, registry keys, event IDs, ports, durations) with fewer false alarms; in hide mode only fully checked answers are shown.
- **A small file can no longer hold the worker** shared by every customer (chunking was quadratic and ran outside the reader's limits). OCR programs never outlive a reading; OCR of one picture is time-limited.
- **Deleted documents stay deleted in saved answers**, also when deleted while the answer was being written or checked. Chats are titled with the first question.
- **Secrets follow no new address:** the embedding API key and the SMTP password are dropped when the address (or, for SMTP, port or security) changes; enter them again.
- **LLM answers:** no search text chosen by the model in "nothing found" notes; invisible characters are removed; stricter link filter.

## What changes for you

- Chat titles are the first question (the model no longer writes them).
- New setting **Approval by another person** (Settings, off by default).
- Changing the embedding address or the email server in the panel removes the stored key or password: enter it in the same save.
- New optional settings in `.env`: `MENTIS_EMBEDDING_ALLOWED_URLS` (empty = any), `MENTIS_OCR_TIMEOUT_SECONDS` (default 600). `MENTIS_PARSE_MEMORY_MB` and `MENTIS_PARSE_CPU_SECONDS` now take effect (they were not passed to the containers).
- After the upgrade run **Reprocess all documents** once (Embedding and Qdrant).

## Before the upgrade

```bash
cd ~/mentis
git status --short
./backup.sh
```

## Upgrade

```bash
cd ~/mentis
git fetch --tags
git checkout v0.6.3
docker compose build --pull
docker compose pull --ignore-buildable
docker compose up -d --remove-orphans
docker compose ps
docker image prune -f && docker builder prune -f
```

## Post-upgrade check

```bash
sudo ./check.sh
docker compose exec api python -c "import app; print(app.__version__)"
docker compose exec postgres psql -U mentis -d mentis -c "select version_num from alembic_version"
docker compose logs api worker | grep -i -E "alembic|error|traceback" | tail -10
```

Expected: `0.6.3`; `0016`; no new errors. Then, as super-admin, **Embedding and Qdrant → Reprocess all documents**, and ask a question whose answer has a command or a table: the line under it must be *Matches the sources* or name what does not match.

## Rollback

Migration 0016 is in this version: older images do not start on the upgraded database. Go back with the backup taken before the upgrade:

```bash
cd ~/mentis
git checkout v0.6.2
./restore.sh "$(ls -1dt backups/mentis-* | head -1)"
docker compose up -d --build --remove-orphans
```
