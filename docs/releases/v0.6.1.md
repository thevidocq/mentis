# Mentis v0.6.1

Accuracy release: answers, the answer check, how documents are read and how the index is searched. No migration.

## Added

- **Reprocess all documents** (super-admin, **Embedding and Qdrant**): reads every document again with the current readers, in place. Documents stay in answers; approvals do not change. **Run it once after this upgrade.**

## Fixed

- **Answers**: earlier answers are no longer used as sources and their old citation numbers are not copied; partial answers say what is missing; conflicting passages are both reported; live lists are never counted unless a total is given; names and codes kept as written.
- **Sources**: the passage opened from a citation is the whole passage (was cut at 600 characters).
- **Answer check**: many more value forms checked (phones, AM/PM, ports, ticket/CVE/MITRE codes, hashes); level 2 no longer drops verdicts written "S2"; statements beyond the checked ones are reported; the warning sign sits on the right statement.
- **Reading documents**: scanned PDF pages with a footer, pictures, PDF tables (no more duplicates), Word text boxes, insertions, lists, nested tables, headers and footers, PowerPoint placeholders and numbering, Excel merged cells and formats, web page row/column spans; sections split between table rows and never inside a word, each with its section path.
- **Index**: searches use the versions in use as the database lists them; answers pause during a reindex instead of using a half-built index; "All customers" chats respect each customer's General Knowledge Base setting.

## Before the upgrade

```bash
cd ~/mentis
git status --short
./backup.sh
```

## Upgrade

```bash
cd ~/mentis
git fetch --tags
git checkout v0.6.1
docker compose up -d --build --remove-orphans
docker compose ps
docker image prune -f && docker builder prune -f
```

## Post-upgrade check

```bash
sudo ./check.sh
docker compose exec api python -c "import app; print(app.__version__)"
docker compose logs api worker | grep -i -E "error|traceback" | tail -10
```

Expected: `0.6.1`; no new errors. Then, as super-admin: **Embedding and Qdrant → Reprocess all documents**, and wait for *Last reprocessing: done* (any document listed there kept its previous reading). In the chat: open a citation and check the whole passage is shown.

## Rollback

No migration: going back to v0.6.0 needs no restore.

```bash
cd ~/mentis
git checkout v0.6.0
docker compose up -d --build --remove-orphans
```
