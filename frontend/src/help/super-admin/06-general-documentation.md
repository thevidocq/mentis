# General documentation

**General documentation** holds documents that apply to every customer: shared playbooks, SOC-wide procedures, tool guides.

It works exactly like a customer's Documents page: upload, versions, preview, approval, rename, delete. The rules, accepted formats and quality warnings are described in the tenant admin guide, topic **Documents**.

## How it is used

- Every customer's answers include General documentation, unless that customer turns it off in its settings.
- When General and a customer's own procedure disagree (escalation, SLA), the customer's procedure wins.

## Customer documents

Each customer's documents are managed by its tenant admins, from their own **Documents** page.
